# Static Portfolio Website – HTML & CSS (Assignment Project)

This project is a static portfolio website created using only **HTML** and **CSS** as part of my academic assignment at **SMIT (Saylani Mass IT Training)** under the supervision of **Sir Muhammad Muhatir**.  
The purpose of this assignment is to demonstrate strong fundamentals in structure, layout, and clean design without using JavaScript or external frameworks.
